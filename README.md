# Eulearn

## What Is This Project?

An interactive, browser-based tool for **visualizing and solving graph theory problems**, deployed on Cloudflare's free tier and utilizing its various services (D1, KV, Workers, etc.). Ideally it should have 2 modes:

- **Sandbox mode**: you draw graphs by dragging nodes and connecting edges, then watch algorithms (BFS, DFS, Dijkstra, etc.) animate step-by-step on the canvas with a live explanation panel.
- **Puzzle mode**: curated problems (shortest path, cycle detection, map coloring, the Königsberg bridge problem) that you solve interactively, with solutions validated server-side.
